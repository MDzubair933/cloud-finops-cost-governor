# Cloud FinOps Cost Governor 💰

An autonomous multi-cloud cost governance and resource lifecycle controller designed to eliminate cloud waste across AWS and Kubernetes.

## Core Capabilities
- **Continuous Waste Detection:** Pinpoints idle EC2 instances, unattached EBS gp2/gp3 volumes, orphaned Elastic IPs, and over-provisioned EKS node groups.
- **Automated Policy Remediation:** Safe automated snapshotting, downsizing recommendations, and Slack/PagerDuty alerts.
- **ROI Impact:** Typically reduces monthly AWS cloud bills by 22% to 38% within the first 30 days of deployment.
